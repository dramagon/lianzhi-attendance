# B个人月度考勤验证

## 交付内容

考勤记录页增加PersonalDays组件，复用既有GET /api/attendance/me/days，仅查询当前登录者。支持月份选择、前后月、按日查看、手动刷新、排班日记录/有效工时/获批请假/获批加班/待结算汇总，以及UTF-8 BOM本人CSV。

日详情直接展示后端状态、北京时间签到签退、迟到/早退、跨天说明、计算notes及审批来源；异常状态可跳转既有申请页，仍需手工填写、确认和正常审批，不预填成功或自动提交。无排班记录不视作缺勤，PENDING不提前判定缺卡，不推算不存在日期的工时或出勤率。下方原始事件保留自己的日期筛选和分页；月历日结果不会覆盖原始事件。

切换月份/用户/能力状态立即清除旧结果，使用请求版本及卸载检查隔离旧响应。查询失败明确报错，不显示空汇总；导出只有成功且有数据时可用。CSV字段做转义及公式前缀处理，不导出坐标、口令、二维码、人脸或其他员工数据。没有新增后端接口、迁移或认证旁路。

## 验证范围

前端format与build通过，构建保留原有报表分包体积提示。个人月历3项测试包括：

1. 真正创建合成员工/正式排班/请假申请，经管理员审批后，从本人接口核对月历480分钟及审批来源、实际CSV内容和390px布局。使用服务器时间的次日与全年工作日规则，不修改历史排班。
2. 503查询失败不显示空汇总或允许导出，恢复真实接口后手动重试成功。
3. 浏览器日接口仿真：挂起2月响应后切换3月，等待旧响应实际返回，仍只显示新月份数据；不把仿真当作数据库联调。

初次真实联调测试错误使用过去日期，按现有“不能改写过去日期的正式排班”规则被拒绝。仅修正测试日期，不放宽后端规则或删去业务断言。失败记录保留在/tmp/b-month-e2e.log。

最终完整浏览器49项全部通过，结果见/tmp/b-month-final-e2e.log；离线展示包9项回归通过，见/tmp/b-month-classroom-e2e.log；新功能单独3项通过，见/tmp/b-month-personal-e2e.log；打包/启动边界7项通过。手机截图：artifacts/b-personal-month-mobile.png，自动化浏览器视口不代表真实手机现场验收。

未改动后端业务或公共导航，不重新宣称运行后端346项或MySQL全量回归；历史证据继续保留。无真实SDK或授权依赖，识别/活体仍为未接入，摄像头预览与课堂原文摘录边界不变。Windows启动与真机定位仍需现场确认。

## 使用

员工登录→考勤记录→个人月度考勤。选择月份，点击日期看详情；点击“导出本人月度CSV”下载核对。课堂演示的合成员工有本轮排班与审批记录，整站演示后可点击“恢复上次进度”切回合成员工再查看月历；跨月请假选择次月。最终压缩包及远端同步结果见本轮汇报，main仍由A协调合并。
