# A 登记入口实际操作反馈修复（2026-11-08）

用户继续反馈点击“前往本人登记与授权”看不到反应。上一版仅使用页内锚点，已有登记区域处于上方或视口内时，只有URL/滚动变化，缺少实际操作反馈；上一轮只验证锚点与标题可见，未充分验证用户能找到下一步操作。

入口现改为明确的按钮处理：先释放独立设备预览，调用登记组件的操作入口；滚动至登记区，以蓝色边框高亮，聚焦同意框（已同意则聚焦摄像头或采集按钮），并显示下一步提示。提示随同意、摄像头等待、画面就绪和提交状态变化。不会自动勾选同意、打开摄像头或上传图片。服务不可用时仍不开放。

新增浏览器断言要求真实DOM焦点位于采集同意框、仍未勾选、明确指引可见、没有发生登记请求，不再用URL锚点变化充当操作完成。原有登记、更新、删除、验证及设备释放回归保留。

本轮仅前端修改，后端业务与阈值不变。前端format/build、独立临时库完整浏览器48项通过；后端不重复360项测试。交付包仅替换静态资源，并逐条验证其他JAR内容未变，不包含SDK或数据库。主站实际重启后浏览器复验通过：入口使采集同意框获得焦点、仍未自动勾选，高亮和下一步提示可见；勾选后提示引导开启采集摄像头且按钮可用；前后登记版本不变。该检查未开启真人摄像头、未上传或修改人脸数据。
