## 后端测试项目

1. 未登录不能读取业务数据与个人资料。
2. 登录请求必须携带 CSRF token。
3. 登录成功轮换会话标识。
4. 错误密码返回401和可读提示。
5. 管理员可以查账号，响应不泄露密码哈希。
6. 人事可以读取管理概览，但不能读取管理员账号接口。
7. 员工不能绕过后端访问管理接口。
8. 退出登录后会话失效。
9. 数据库存储 BCrypt 哈希，演示密码可通过正常校验。
10. 非演示模式没有初始密码时拒绝生成默认管理员。

## 环境与边界

本轮在 Linux、OpenJDK 17、Node.js 24 和 Chromium 上实际验证。前端推荐给组员统一使用 Node.js 22 LTS；最低版本见 package.json。

尚未在用户 R9000P 上执行 Windows 脚本，也未连接真实 MySQL、虹软 SDK、摄像头或地图/AI服务。MySQL 配置与迁移已提供，但不能将 H2 验证等同于真实 MySQL 验证。

GitHub Actions 配置会执行后端测试、前端构建和浏览器测试；具体执行状态以仓库 Actions 页面为准，本地通过不等同于远端流水线已经通过。

当前为本地实训基础版本。完整的公网部署、账号维护、密码修改与重置、登录限流和操作审计，需在后续模块和部署阶段补齐。
