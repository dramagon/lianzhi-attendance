## 本日实现

- 独立、有限额的内存工作区串联真实解析、规范化、切片、权限过滤、文字匹配、向量余弦检索及引用。它不是 Spring Bean，不接 HTTP，不用于生产保存；只作为集成前的可执行逻辑与测试夹具，重启即失去数据。
- 内部 Actor 只能由未来认证/组织桥接层生成，不接受 HTTP 身份声明。ADMIN 全局，HR 本公司，员工本公司 COMPANY 文档及本人 PRIVATE 文档；未分配公司非管理员拒绝业务。员工只能维护本人的 PRIVATE 文档。
- 更新采用 expectedVersion；接受新版本时立即移除旧正文/索引，失败不回退旧内容。处理完成按版本比较发布，删除或后续更新使旧处理结果失效。删除先保留墓碑阻断读取，不让旧引用复活。检索在排序/截取之前过滤权限，向量查询返回前再次校验版本与权限。
- 来源包含 documentId/version/chunk/section/source/码点偏移，引用读取重新鉴权，只返回当前有效版本；旧版链接返回不存在。
- 实现 Ollama `/api/embed` 的配置适配器，发送 truncate=false；固定服务端 URL，不接受请求提供的 URL。有限批量、超时、响应字节数、维度/数量/有限非零数值校验；失败不泄漏提供方正文，不生成替代向量。真实外部服务未配置，不宣称联通。
- 内部精确余弦排序消费真实提供方输出，不依赖假向量或关键词伪装；合成向量只允许在明确的单元测试夹具中。未实现持久化向量数据库或大规模 ANN。
- HTTP 只开放受现有认证保护的能力状态；上传/列表/检索/引用/更新/删除均明确 503，不以假列表、假 ID 宣称业务完成。写请求继续由现有 CSRF 拦截。知识库模块页面显示依赖状态并禁用操作，导出 routes.js，根菜单/路由交由 A 整合。
