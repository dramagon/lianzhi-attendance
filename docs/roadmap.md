# 模块规划

技术基线：Java 17 + Spring Boot 3.5 + MyBatis + Vue 3 + Vite + Element Plus + Pinia。使用 Flyway 管理数据库版本；MySQL 为目标业务数据库，H2 文件库用于本地快速演示。

当前为模块化单体工程，先验证业务和权限。Nacos、OpenFeign 等微服务组件在有明确服务边界后接入；第一阶段没有宣称完成微服务、集群或云部署。

| 阶段 | 模块 | 当前状态 | 主要验收点 |
| --- | --- | --- | --- |
| 1 | 系统基础与登录权限 | 已实现 | 三角色登录退出、后台框架、员工首页、接口权限与数据库持久化 |
| 2 | 公司、员工与办公场所 | 开发中 | A1基础档案、范围、绑定、本机MySQL及真实高德地图选点已验证；实际设备定位待验证 |
| 3 | 二维码与基础考勤 | 主体已整合，待真机验证 | 二维码有效期、定位、打卡幂等、迟到早退规则；本机浏览器与MySQL回归已覆盖 |
| 4 | 人脸识别考勤 | 待开发 | 人脸采集、比对、活体检测、识别失败处理 |
| 5 | 考勤业务与审批 | 开发中 | A2.2真实保存、审批审计和B考勤同事务回写已接通；已生效撤销暂不支持 |
| 6 | 数据分析与报表 | 待开发 | 按部门与日期统计、工时、趋势和导出 |
| 7 | 企业知识库与 AI 助手 | 基础组件与本人业务查询已整合 | 只读考勤/申请查询已接通；知识库持久化、上传/检索及真实模型问答仍未开放 |
| 8 | 移动适配与多端使用 | 待开发 | 手机扫码、摄像头、定位、uni-app；第一阶段已有基础响应式布局 |
| 9 | 部署、集成与交付 | 待开发 | Redis、任务调度、微服务集成、容器、流水线与完整交付 |

每个阶段交付运行步骤、数据库迁移、接口说明与相应的功能验证。外部地图服务、人脸 SDK 和 AI 服务在接入时确认凭据与可用平台。

第二阶段已在 `identity` 外新增 `organization`、`employee`、`workplace`，对外DTO不含敏感字段。接口和B/C接入见 [A模块文档](modules/a-api.md)。审批已在B正式V3后接通V4与调整服务。
