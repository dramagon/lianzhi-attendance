# 模块规划

技术基线：Java 17 + Spring Boot 3.5 + MyBatis + Vue 3 + Vite + Element Plus + Pinia。使用 Flyway 管理数据库版本；MySQL 为目标业务数据库，H2 文件库用于本地快速演示。

更新：2026-11-09。以下按已整合代码、本机验证和用户现场反馈记录，替代早期“待开发”状态；不把本机、浏览器仿真和正式环境验收混为一项。当前仍为模块化单体。B/C云端交付已整合：Redis共享会话在A本机真实双实例验证，Nacos/OpenFeign独立向量服务已有C与远端CI证据，Kubernetes已有kind CI证据；后二者未在A本机运行。uni-app已通过本机H5及微信小程序构建，手机现场和云效仍待验收。
