# Windows 本机人脸现场测试

先构建后端，安装官方Windows x64 ArcFace Java V3.0运行库并将APPID、SDKKEY放到 `artifacts/arcsoft-credentials.local.ps1`。本机路径同 `docs/modules/face-setup.md`。双击根目录 `start-face-test.cmd`，窗口出现 `FACE_TRIAL_READY` 后打开 http://127.0.0.1:18081 。保持窗口打开；Ctrl+C退出并清除内存参照。

勾选当前采集者同意，开启摄像头，先由本人采集一张参照，再采集至少三次本人样本（适当改变距离、光线）。随后切换非本人样本，由另一位同意测试的人采集至少三次。也应测试照片、屏幕、多人、低光和偏转等拒绝场景。页面分别显示人数、基础质量、RGB活体或实际比对分数。单人和活体未通过时不提取可用特征，不显示假分数。

工具不保存照片、特征、分数，不访问业务数据库，也不会自动调整身份比对阈值。参照特征仅暂存当前工具内存，清除按钮、撤回同意、离开页面会请求清除；异常断网/浏览器强退无法保证清除请求送达，此时关闭工具窗口。摄像头停止、切后台时释放设备，采集失败不会自动重试。暂存特征在工具进程关闭时清零；不宣称Java能控制SDK所有内部缓冲。

本机HTTP服务只绑定127.0.0.1:18081，写请求校验精确Host、Origin和随机令牌，单次图像不超过2MiB；SDK调用串行。无需登录员工账号，该工具仅由开发/验收人员在本机显式启动，不放进生产应用或对外代理。跨机器摄像头应使用正式应用的HTTPS采集与权限流程。

收集并记录本人最低分、非本人最高分和测试场景，样本分数重叠时不能启用；有间隔也不代表已证明正式环境准确率或防攻击水平。确认合适阈值后，由维护者在本机明确设置 `LIANZHI_FACE_MINIMUM_SCORE` 并重启应用，再完成登记、更新、删除、挑战及打卡完整验收。不得以固定阈值代替现场测试。
